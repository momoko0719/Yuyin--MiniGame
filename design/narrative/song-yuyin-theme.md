# 原型曲目：《余音》主题（暂名）

*用途：原型阶段的 Suno 生成曲，验证「一首歌就是一场战斗」*
*创建：2026-09-01 | 修订：2026-09-01（去说唱、去电音，改为旋律向古风流行）*

---

## Suno Style 标签

```
mandopop, chinese style pop rock, guofeng, melodic, strong catchy hook,
live drum kit, electric bass, clean electric guitar, pentatonic melody,
pipa riff, dizi accent, guzheng pluck, young clean male vocal,
bright tenor, fully sung melody, driving, 140 BPM, 4/4
```

## Exclude styles

```
rap, hip-hop, trap, 808, EDM, electronic, synth, dubstep, autotune,
epic, cinematic, orchestral, opera, folk, choir, ballad, 80s, 90s
```

参考气质：《千丝戏》《霍元甲》《权御天下》——
**真乐队编曲 + 民乐当钩子 + 年轻男声一路唱到底**。
不说唱、不电音、不做电影配乐。

## 与剧情的对应

- **"那夜的刀 一下 又一下 / 太过整齐 像谁数着开场"** ——
  序幕灭门那晚，沈砚在琴匣里听到的军队鼓令
- **"不抢不拖 一板一眼"** —— 师父段拙的口头禅，也是板眼武学的核心
- **"敲我七年的木头 现在跟我走"** —— 师父那截敲了七年后脑勺的刀鞘
- **"他们杀人 也踩着拍子入场"** —— 反派韩铎以鼓令指挥的军队
- **"把那面鼓砸响"** —— 终局，两种节奏的对撞
- **Bridge 那四句是全曲的情感锚点** ——
  "他数拍子的时候总是跑调 / 现在换我来数"，
  直接对应终局静音段玩家听见的那段跑调哼声

## 段落与战斗阶段的映射

| 曲式 | 战斗阶段 |
|---|---|
| Intro | 对峙、试探，教玩家听拍 |
| Verse | 攻防往来，读招攒气 |
| Pre-Chorus | 压迫感上升，BOSS 准备破防 |
| **Chorus** | **破防爆发窗口 —— 伤害翻倍** |
| Bridge | BOSS 转阶段，喘息 |
| Outro | 处决 / 收尾 |

## 生成时的挑选标准

不只看好不好听，重点看：

1. **副歌与主歌的能量落差够不够大** —— 副歌要当爆发窗口，越炸那几秒越爽
2. **Bridge 有没有真的降下来** —— 那是转阶段和情感锚点
3. **鼓点清不清晰** —— 节拍检测和玩家听拍都靠它
4. **BPM 稳不稳** —— 不要变速的（变速处理留到后面）
